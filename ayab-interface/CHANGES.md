# AYAB Interface (formerly "AYAB Shield v2") Release Changes


## Version G

- KH-910 connector J5A pin 7 (right sensor lace carriage signal, EOLR_LACE) no longer grounded, routed to D7 and D8 instead (see ayab-firmware#226)
- Arduino AREF pin no longer connected to 5V
- Copper OSHW logo replaced with silkscreen-only version
- Woolly Logic logo and PCB code removed
- "AYAB Interface Rev G" board name and revision added to top silkscreen
- "Knitting Machine Control Board" title replaced with silkscreen AYAB logo and tagline
- D7 and D8 labelled D7/EOLRL and D8/DET in silkscreen
- R3 value changed from 320 Ω to 330 Ω to match the BOM

## Version F

- Fiducial marks removed from top of PCB
- Two holes removed
- Assembly tab removed
- Secret message removed
- EMS catalog number removed and Woolly Logic PCB code substituted
- OSHW logo added
- Woolly Logic logo added
- SMD Tantalum capacitor substituted for SMD electrolytic capacitor C3
- Woolly Logic PCB code KI01

## Version E

Evil Mad Science catalog number EMS 60-0043/E
